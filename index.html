How to use this tracker

Open a day, tick each video only after watching it, and tick practical tasks only when you have completed them. Your progress is saved in this browser automatically. Use Export progress to keep a backup.

Learning note: finishing a video is not the same as mastering a skill. For each circuit, record whether it is only studied, simulated, reviewed against datasheets, or physically tested.

Portfolio quality rule

For every project, include a clear brief, schematic, PCB layout, component choices, ERC/DRC results, manufacturing outputs and a truthful verification status. A clean DRC report does not prove that the circuit works.
